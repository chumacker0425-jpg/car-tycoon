# 造車大亨：我的車廠

以 HTML、JavaScript 和 Three.js 製作的單人網頁遊戲，包含車廠經營、車款研發、賽車與開放世界駕駛。

## 執行

使用靜態網頁伺服器提供 `造車大亨_我的車廠.html`，並在支援 WebGL 的瀏覽器中開啟。
目前 Three.js 和 GLTFLoader 由外部 CDN 載入，需要網路連線。

## 存檔

進度保存在瀏覽器的 localStorage，自訂模型保存在 IndexedDB。存檔不會跨裝置同步；網站網址或瀏覽器變更時，也不會自動移轉。

## 目前已知問題

- 存檔尚未保留產線中的車輛及加工進度。
- 讀檔時會使用玩家售價重算車款基準價格與成本。
- 模型內嵌於 HTML，檔案約 21 MB，首次載入有優化空間。

## GitHub 同步

每次更新完成後，先詢問使用者是否要同步到 GitHub。上傳程式碼不等於已發布可玩的網站。
